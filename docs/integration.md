## Какой AI подключён

По указанию владельца основной AI использует переданный API:

```dotenv
CQA_AI_PROVIDER=openai-compatible
CQA_LLM_BASE_URL=https://api.aijuju.rest/v1
CQA_LLM_MODEL=gemini-3.8-flash
CQA_LLM_API_KEY=<key>
CQA_LLM_API_ENABLED=1
CQA_LLM_MAX_ATTEMPTS=1
CQA_LLM_RPM=15
CQA_LLM_TIMEOUT_SECONDS=75
CQA_EVALUATION_TIMEOUT=240
CQA_AI_CONCURRENCY=1
```

Ключ уже установлен в локальном `.env` общей рабочей копии. Файл исключён из Git.
Backend отправляет запросы на `/v1/responses`; браузер обращается только к backend
и ключ не получает. `Evaluator`, восемь критериев, N/A, цитаты и формат оценок сохранены.
Баллы рассчитывает backend. Локальная GPU для этого режима не нужна.

`.env.example` содержит только пустые ключи; платные вызовы в примере выключены
до явного включения. Настоящий ключ передаётся backend-разработчику отдельно.
Для GPU-варианта остаются `local-http` и `local-lora`, но они не выбраны в этой версии.

## Получение и запуск одним сервером

```text
git clone --single-branch --branch codex/integration https://github.com/8zellorr8/data_ch.git
cd data_ch
```

Из корня проекта, PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]" -c requirements-lock.txt
if (-not (Test-Path -LiteralPath .env)) { Copy-Item .env.example .env }
```

При новом клоне заполните локальный ключ и параметры выше. Существующий `.env`
перезаписывать не нужно. На компьютере владельца ключи и настройки уже перенесены.

```powershell
$env:CQA_FRONTEND_PATH = (Resolve-Path frontend).Path
.\.venv\Scripts\python.exe -m uvicorn ai.app:create_hosted_app --factory --env-file .env --host 127.0.0.1 --port 8101 --workers 1 --timeout-graceful-shutdown 260
```

Откройте **http://127.0.0.1:8101/** — frontend и API работают на одном адресе.
Swagger: http://127.0.0.1:8101/docs. Настройки выбранного провайдера:
`GET /api/v1/ai/status`; ожидается `openai-compatible`, `gemini-3.8-flash`,
`usage_is_local=false`. Остановка — Ctrl+C. Для Linux/macOS используйте `.venv/bin/python`.

Можно также запускать frontend отдельным сервером по README. Его proxy ждёт
245 секунд, браузер — 250, backend — до 240. Постоянный ключ запроса позволяет
восстанавливать потерянный ответ без повторного платного вызова.

## Учёт расхода

Текущая общая версия использует существующий ledger владельца по абсолютному пути,
указанному в локальном `CQA_LLM_BUDGET_PATH`. При объединении веток он не обнулён.
В нём общий лимит 7 млн, исходный расход 809 тыс. со слов владельца и резерв
5 191 000; обычная тестовая фаза ограничена 1 млн новых токенов.

При переносе на другой сервер перенесите существующую SQLite-БД учёта и задайте
её новый путь. Не создавайте независимые пустые счётчики для параллельных backend:
лимит действует на один ledger. Для одного общего счётчика используйте один активный
backend и его штатную очередь. Сам ledger, как и `.env`, не входит в Git.

`CQA_LLM_RPM=15` задаёт локальное ограничение частоты; это не подтверждённая
квота aijuju. Паузы `429` и `Retry-After` сохраняются в SQLite и видны frontend.
После неоднозначного сетевого исхода автоматический повтор не разрешается.
Если провайдер не сообщил usage отказа, резерв токенов остаётся консервативно занятым.

На единственный реальный тест интеграции провайдер сообщил **3231 входной + 803 выходных
= 4034 токена**, неопределённых запросов нет. Новый счётчик не создавался.
Эти числа — usage API, не независимая проверка биллинга aijuju; баланс кабинета
по-прежнему не подтверждён. Настройки ограничителя не заменяют лимит самого провайдера.

## Что проверено

- Объединение сохраняет backend и свежие frontend-сценарии, а также все AI-адаптеры.
- Через браузер открыт учебный RU-диалог и запущен настоящий aijuju запрос.
  Gemini 3.8 Flash вернул восемь ответов за 11,86 секунды; backend проверил цитаты,
  рассчитал балл и сохранил результат в историю SQLite.
- Проверены программные тесты backend/AI, frontend и локального proxy.
  Детальные числа находятся в [integration-validation.json](integration-validation.json).
- Исходные ключи и `.env` не попали в Git; запросы к `/.env`, `/.git/config`
  и `/backend/schema.sql` возвращают 404.

Учебный результат 100/100 подтверждает подключение и работу цепочки, а не точность
модели на реальных чатах. Экспертная разметка и продуктовый FAQ не добавлены.
Отдельные метрики Qwen4B относятся к локальной модели и не являются метриками этого API.
