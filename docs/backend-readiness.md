# Приёмка backend перед подключением AI

7 ноября 2026 года. Проверена доработка после `4e6f24a` в ветке
`codex/backend-core`; точная ревизия этого отчёта — содержащий его Git-коммит.
Окружение: Windows, Python 3.12.14, зависимости существующего venv.
Новая установка из чистого клона в этом прогоне не выполнялась; предыдущая
проверка зафиксирована отдельно в [backend-no-ai.md](backend-no-ai.md).

Рабочая база alwaysdata не открывалась и не изменялась. Uvicorn запускался
на loopback с временной SQLite, существующим frontend и UnconfiguredEvaluator.
По завершении сервер остановлен и временная база удалена.

## Автоматические проверки

```text
python -m pytest -q
python -m ruff check backend scripts tests
python -m ruff format --check backend scripts tests
python -m mypy backend
```

Результат: **268 тестов прошли**, Ruff и форматирование прошли (54 файла),
mypy прошёл (31 файл backend). Есть предупреждение установленной Starlette
об устаревании использования httpx в TestClient; падений нет, зависимости
ради его подавления не менялись.

В новые проверки входят внедрение Evaluator в hosted-приложение, одиночная
и пакетная обработка одним адаптером, резервирование результата, работа без AI,
HTTP/локальный экспорт на одинаковых исходах, DEV/PROD, явные исходы и batch_id,
тайм-ауты и сетевые ошибки, повреждённый/слишком большой JSON, несоответствие
выбора, защита файла и отсутствие публикации при ошибке. Тестовый Evaluator
существует только в тестах и не подтверждает качество реальной модели.

## Настоящий HTTP-сервер без AI

- Существующий `scripts/frontend_kit.py` прошёл 16 HTTP-шагов: импорт,
  пользовательский чек-лист, ручная оценка с N/A, апелляция, конфликт повторного
  открытия, экспорт, ожидаемые 422 и 404.
- Автоматическая оценка вернула 503 с кодом AI_NOT_CONFIGURED.
- После остановки и повторного запуска Uvicorn сохранились весь набор, оценки
  и история. Сравнивалось содержимое экспорта без меняющегося `exported_at`.
- Новая CLI действительно запускалась отдельным процессом против HTTP API:
  65 синтетических DEV (60 чатов/5 звонков), 10 синтетических PROD-чатов.
  Все исходы были явно обозначены AI_NOT_CONFIGURED; это проверка выгрузки ошибок,
  не прогон модели. Файлы лежали во временной папке и не попали в results/.
- Повтор без --overwrite отвергнут; явная перезапись прошла.

## Что ещё не подтверждено

- Реальный вызов Gemini, его точность, RU/KZ/EN, новые диалоги и произвольные правила.
- Полный контрольный прогон за один час с настоящими результатами и push.
- Истинный расход модели и поведение её клиента при лимитах/сбоях.
- Полная ручная приёмка M01–M14, включая замену критерия с последующей AI-оценкой.
- Установка/проверка nginx-шаблона и включение защиты публичного сервера.

Развёрнутый сайт пока остаётся на `4e6f24a`: HTTP-выгрузка совместима с его API,
но внедрение адаптера в hosted-фабрику нужно развернуть при интеграции AI.
CI запускается для коммита этой доработки; окончательный результат смотреть
в GitHub Actions именно этого SHA, а не у предыдущего релиза.
