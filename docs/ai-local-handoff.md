# Передача локального AI backend-разработчику

Выбран **Qwen3-4B-Instruct-2507 с обученным QLoRA-адаптером**. Обучение выполнено на RTX 3050 Laptop 6GB. Платный aijuju выключен, автоматического перехода на него нет. Исходный контракт `Evaluator` и JSON оценки сохранены; баллы, веса и N/A пересчитывает backend.

Это **предварительный оценщик для проверки человеком**: 77/96 совпадений с черновыми метками на 12 отложенных текстовых чатах, MAE балла 11,03. Частотный прогноз без чтения чата даёт 76/96 и MAE 12,35. Единственное грубое нарушение в текстовой validation пропущено. Пять звонков обработаны технически, но совпадений только 20/40, MAE 26,68; они не участвовали в обучении. Нельзя представлять модель как безошибочный автономный контроль качества.

Результаты и ограничения: [ai-local-4b-validation.json](ai-local-4b-validation.json). Предыдущая 1.7B на тех же 12 текстах выдавала одинаковый набор ответов; её [старый отчёт](ai-local-validation.json) оставлен с предупреждением.

## Готовый API на компьютере владельца

| Назначение | URL |
| --- | --- |
| Backend / Swagger | `http://127.0.0.1:8001/docs` |
| Backend health | `http://127.0.0.1:8001/health` |
| Выбранный провайдер | `http://127.0.0.1:8001/api/v1/ai/status` |
| GPU worker / Swagger | `http://127.0.0.1:8002/docs` |
| GPU worker health | `http://127.0.0.1:8002/health` |

`127.0.0.1` относится к этому компьютеру. Сервер alwaysdata не получает к нему доступ автоматически. Создание внешнего туннеля было отклонено автоматической проверкой (`blocked by policy`); публичный endpoint не создан. Для удалённого backend нужен доступный ему GPU-хост с HTTPS и тем же worker. Полный backend с данными наружу выставлять для этого не требуется.

Worker принимает `POST /v1/evaluate` с заголовком `Authorization: Bearer <worker-key>` и телом:

```json
{
  "conversation": {"...": "полный backend.models.Conversation с ID сообщений"},
  "checklist": {"...": "полный backend.models.ChecklistVersion"}
}
```

Это схема; готовое синтетическое тело находится в [examples/local-worker-request.json](../examples/local-worker-request.json), точные поля доступны в Swagger. В ответе `result: EvaluationResult`, `metadata: AIModelMetadata`, `usage_is_local: true`. Итоговых баллов в ответе worker нет. Клиент повторно проверяет значения и дословные цитаты по исходному контексту. Тарифные токены aijuju здесь не используются; `input_tokens`/`output_tokens` описывают локальную генерацию.

Ключ worker отдельный, не ключ aijuju. Он уже находится в локальном `.env`, который исключён из Git. Не пересылайте весь `.env`: для подключения удалённого backend достаточно отдельных настроек worker. В репозитории только пустой [.env.example](../.env.example). Приватность GitHub не заменяет хранение секретов вне Git.

## Подключение CPU-backend к GPU-worker

Перенесите изменения ветки `codex/ai-gemini`, включая `ai/http_worker.py`, `ai/worker_protocol.py`, `ai/config.py` и `ai/app.py`, сохранив остальные настройки хостинга. ML-библиотеки на CPU-backend не нужны.

```dotenv
CQA_AI_PROVIDER=local-http
CQA_LOCAL_AI_URL=https://YOUR-GPU-HOST
CQA_LOCAL_AI_KEY=<key>
CQA_LOCAL_AI_TIMEOUT_SECONDS=210
CQA_EVALUATION_TIMEOUT=240
CQA_AI_CONCURRENCY=1
CQA_LLM_API_ENABLED=0
```

Для backend на том же компьютере URL уже настроен как `http://127.0.0.1:8002`. Запуск:

```text
python -m uvicorn ai.app:app --env-file .env --host 127.0.0.1 --port 8001 --workers 1
```

На alwaysdata используйте прежнюю hosted-фабрику `ai.app:create_hosted_app --factory` и её параметры хоста/порта из [инструкции хостинга](alwaysdata.md). Она также поддерживает `local-http`. Добавление ключа без изменения запуска и провайдера AI не включает.

В собственном backend:

```python
from ai.config import build_evaluator
from backend.main import create_app

app = create_app(evaluator=build_evaluator())
```

Проверка: `/health` → `ai_configured=true`; `/api/v1/ai/status` → `provider=local-http`, `usage_is_local=true`, `paid_fallback=false`. После реального запроса метаданные оценки должны содержать `local-qwen3-4b-instruct-2507-cqa-qlora`.

Один worker обслуживает одну GPU. Пакетная очередь backend уже сохраняет прогресс в SQLite. При занятой GPU worker возвращает 429, клиент преобразует это в `AI_BUSY`; повторы планирует очередь backend. Ошибки ключа дают `AI_NOT_CONFIGURED`, таймаут — `AI_TIMEOUT`, недопустимый ответ — `AI_INVALID_RESULT`. Платных повторов нет.

## Установка на другой GPU-хост

Адаптер поставляется отдельным ZIP в приватном [релизе Qwen4B](https://github.com/8zellorr8/data_ch/releases/tag/cqa-local-qwen3-4b-20261108), вместе с SHA-256. Исходный JSON, реальные диалоги, база 2,65 GB и секреты в архив не входят. Извлеките ZIP в корень checkout: должен появиться `data/lora/qwen3-4b-cqa/adapter/` и соседний манифест.

Создайте ML-окружение по [ai-lora.md](ai-lora.md), затем скачайте закреплённую базу и проверьте веса:

```powershell
.\.venv-train\Scripts\python.exe -m ai.install_local
```

Команда использует публичный Hugging Face без платного inference API, проверяет SHA-256 адаптера и файлов базы и записывает локальный путь базы в конфигурацию адаптера. Если база уже скачана:

```powershell
.\.venv-train\Scripts\python.exe -m ai.install_local --existing-base --base data/models/qwen3-4b-instruct-2507-nf4
```

Параметры GPU-host в его `.env`:

```dotenv
CQA_LORA_ADAPTER=data/lora/qwen3-4b-cqa/adapter
CQA_LORA_DEVICE=cuda
CQA_LORA_MAX_NEW_TOKENS=1280
CQA_LORA_TIMEOUT_SECONDS=180
CQA_LOCAL_AI_KEY=<key>
CQA_LLM_API_ENABLED=0
CQA_KEEP_AWAKE=1
```

```text
python -m uvicorn ai.worker:app --env-file .env --host 127.0.0.1 --port 8002 --workers 1
```

Для внешнего хоста настройте HTTPS reverse proxy к worker, сохранив Bearer-заголовок и таймаут более 180 секунд. Без ключа worker не запускается; проверка авторизации происходит до разбора тела и вызова модели. Вход ограничен 1 MB. Для полного локального стека Windows предусмотрен `powershell -ExecutionPolicy Bypass -File scripts/start_local_ai.ps1`: он запускает один GPU-worker и CPU-backend с прежней БД `data/local-ai-service.sqlite3`. Порты перед запуском должны быть свободны.

В прямом режиме на GPU можно оставить `CQA_AI_PROVIDER=local-lora` и `ai.app:app` без отдельного worker. Не запускайте оба варианта с двумя копиями модели на одной 6GB GPU.

## Что проверено и что требует внимания

Обучение: 48 текстовых чатов, 12 отложены, 3 эпохи / 36 шагов за 26 мин 29 с. Обучены 16 515 072 параметра адаптера. База заморожена. Метки предварительные; выбор эпохи и профиля промпта использовал ту же validation, независимого теста нет.

Отдельно проверены RU/KZ/EN, N/A, допустимые шкалы, точные цитаты и все пять транскриптов звонков. Максимальный проверенный вход — 9539 токенов. Длинный текст читается блоками по 512 токенов, без обрезания. Манифест ограничивает вход 12288 токенами; превышение возвращает ошибку. Аудио не скачивается и не анализируется.

Четыре синтетических контроля пройдены: вежливый оператор, грубый оператор, грубый клиент, команда клиента изменить оценки. Последний использует узкий фильтр команд в копии промпта и пометку `needs_review`; исходные реплики и цитаты сохраняются. Это не доказательство защиты от произвольных атак. Без продуктового FAQ консультация требует проверки, без аудио — ведение звонка.

Не выбирайте модель только по сниженному loss или допустимому JSON. Слабые места в распознавании нарушений и звонков остаются в отчёте. Перед сдачей результатов нужна содержательная проверка человеком. Обучение и измерения выполнены на исходных восьми критериях; смысловое качество после изменения чек-листа нужно проверять отдельно.

## Купленные токены

В текущем GPU-обучении и локальных HTTP-тестах новых платных генераций **0**, новых платных токенов **0**. Не нужно расходовать 1–2 млн только ради числа: это верхние ограничения пользователя.

Покупка 7 млн и прежний расход 809 тыс. известны со слов владельца. Расчётный остаток — 6 191 000; реальный баланс в aijuju не подтверждён. Стандартные read-only маршруты баланса вернули 404, кабинет требует входа и reCAPTCHA. Локальный ledger не заменяет проверку кабинета и может считать иные единицы, чем биллинг провайдера.

Сохранён резерв 5 191 000. Если в будущем отдельно включить платные тесты, настройки разрешают максимум 1 000 000 новых токенов: общий предел этой фазы 1 809 000, ниже 2 млн. Сейчас `CQA_LLM_API_ENABLED=0`, `CQA_LLM_USE_JURY_RESERVE=0`.

```powershell
.\.venv-dev\Scripts\python.exe -m ai.budget data/aijuju-jury-budget.sqlite3
```

Учёт действует на настроенный ledger, а не на чужие процессы и не на кабинет aijuju. Ключи не коммитить; приватный backend передавать отдельно от секретов.
